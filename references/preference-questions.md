# 偏好问题

已经在行程 md 或旅行者笔记里有答案的，不要再问。一次只问 3–4 个。

## 必问

1. **这次最想要什么？**（多选）文化历史 / 美食 / 购物手工艺 / 海滩自然 / 运动体验 / 放松 spa / 拍照出片
2. **日子怎么分？** 例如：一天运动体验 + 一天文化 + 一天随便逛 + 一天机动。让用户挑或改。
3. **能接受的最长单程车程？** 1 小时 / 2 小时 / 3 小时以上。超过的一日游从方案里砍掉。
4. **预算档次？** 便宜又方便 / 中等 / 不在乎价格。价格用欧元为主给阶梯（便宜到贵），让用户挑。
5. **和谁一起？** 同行者决定 spa、夜间活动、着装和安全的写法。

## 按目的地选问

- 有没有想**学会一件具体的事**（例如辨别香料、买地毯、学做一道菜）？有的话该主题要写成深度专题（见 research-dimensions F）。
- 要不要**本地人的生活视角**（本地人做什么运动、去哪吃饭）还是游客路线？默认给本地视角。
- 有没有**一定要去的地方**，和**一定不去的地方**？
- 要不要**买东西带回去**？带什么、给谁？决定购物调研的深度。
- **住宿区域**对夜间出行的影响：晚上想不想出门？怎么回？
- 有没有**宗教或文化上想了解的**，或者担心冒犯的？
- 旅行中要不要**实时陪伴**（问路、问价、问晚上去哪）？要的话约定用什么渠道。

## 交付

- 要什么形式？笔记 / PDF / 手机卡片，要不要双语（语言组合）？
- 打算**公开发布**吗？是的话个人信息不进成品，图片要署名。

## 提问方式

- 在 Claude Code 里用选择题。
- 在聊天软件里一次只问一个，问完根据答案再问下一个。
- 用户的话乱或自我矛盾时，先复述更正后的版本再确认。
